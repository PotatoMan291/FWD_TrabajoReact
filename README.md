# TechStore

TechStore es una tienda de tecnología desarrollada con React y Vite como parte de una práctica de desarrollo web moderno.

El proyecto presenta una interfaz de comercio electrónico enfocada en productos tecnológicos, organizada mediante componentes reutilizables de React. La página incluye una sección principal, categorías de productos, productos destacados, promociones y un pie de página informativo.

## Tecnologías utilizadas

- React
- Vite
- JavaScript
- HTML5
- CSS3
- Node.js
- npm

## Características

- Interfaz moderna para una tienda de tecnología.
- Diseño basado en componentes reutilizables.
- Navegación entre las principales secciones de la página.
- Sección de categorías populares.
- Catálogo de productos destacados.
- Tarjetas de productos generadas dinámicamente.
- Banner de ofertas especiales.
- Diseño responsive para computadoras, tablets y dispositivos móviles.

## Estructura de componentes

La interfaz está dividida en los siguientes componentes principales:

- `Header`: barra de navegación y carrito.
- `Hero`: presentación principal de la tienda.
- `Categories`: categorías de productos disponibles.
- `Products`: listado de productos destacados.
- `ProductCard`: componente reutilizable para representar cada producto.
- `PromoBanner`: sección de promociones y descuentos.
- `Footer`: información y enlaces adicionales.

## Instalación y ejecución

Clonar el repositorio e ingresar al directorio del proyecto:

```bash
git clone <URL_DEL_REPOSITORIO>
cd mi-proyecto
```

Instalar las dependencias:

```bash
npm install
```

Ejecutar el servidor de desarrollo:

```bash
npm run dev
```

Vite mostrará en la terminal la dirección local donde se encuentra disponible la aplicación, normalmente:

```bash
http://localhost:5173/
```
